# 인스타 B계정 담당

## 부계정 정체성 확정

**계정 아이디:** nego.saimdang
**계정 성격:** 소비자가 보는 계정 → "믿고 따라가고 싶은 사람"
**핵심 포지션:** 유통의 참견 — 쇼호스트 내부자가 유통 구조를 뜯어보는 계정

**확정 프로필명:**
서사임당 | 유통의 참견

**확정 소개문구:**
2,500회 방송한 쇼호스트가 유통 구조를 뜯어봅니다
공구·마진·후기·특가 — 안 보이는 것들을 보여드려요
워킹맘 소비자의 눈 + 쇼호스트 내부자의 귀

**콘텐츠 4개 축:**

[A타입 - 폭로/분석형] 알고리즘 반응 최강
공동구매 마진 구조 해부 / 후기 조작하는 방법 5가지 / 라이브커머스 특가의 진짜 의미
공구 제품 원가 추적 / 팔로워 10만이면 제조사가 먼저 연락오는 이유

[B타입 - 교육/기준형] 저장률 최강
공동구매 참여 전 체크리스트 3가지 / 이 표현 나오면 의심하세요
성분표 읽는 법 / 환불 거부당했을 때 대처법 / 리뷰 신뢰 기준

[C타입 - 공감/경험형] 댓글 최강
나도 링크 오면 그냥 샀어요 / 유명인이 파는 거라 믿었는데
같은 제품 가격이 다른 이유 / 방송에서 안 보여주는 것들

[D타입 - 비교/검증형] 공유율 최강
오픈마켓 vs 공구 직접 비교 / 광고비 리뷰 vs 직접 산 리뷰
성분 같은데 가격 3배 차이 / 유통 단계별 가격 차이

**촬영 스타일:**
- 방송 끝난 직후 / 차 안 / 장비 정리하면서 / 택배 뜯으면서
- 화려한 자막 금지 / 쇼호스트 모드 금지 / 홈쇼핑 톤 금지
- 현실 말투 / 낮은 텐션 / 카메라와 대화하는 느낌

**이번 주 찍을 우선순위 5개:**
1. 공구라고 다 싼 거 아닙니다
2. 쇼호스트가 제품 받으면 제일 먼저 보는 것
3. 사장님께 이 가격으론 소개 못 한다고 했습니다
4. 저도 링크 오면 그냥 산 적 많아요
5. 좋은 제품인데 못 파는 사장님들 특징
