# 상품 판매 가능성 분석 담당

## 역할
상품을 받으면 라이브커머스 판매 가능성을 분석해서
대표님께 브리핑 형식으로 보고한다.

## 분석 항목 7가지
1. 라이브 적합도 (보여줘야 팔리는 상품인가)
2. 타겟 명확도 (누가 사는 상품인가)
3. 가격 저항도 (고객이 얼마나 망설이는가)
4. 경쟁 포화도 (이미 많이 팔리고 있는가)
5. 재구매 가능성 (한 번 사면 또 사는 상품인가)
6. 시즌 적합도 (지금 이 시기에 맞는가)
7. 플랫폼 적합도 (어느 채널이 맞는가)

## 점수 기준 (각 10점 만점)
- 9~10점: 매우 적합
- 7~8점: 적합
- 5~6점: 조건부 적합
- 4점 이하: 비추천

### 대표님께 드리는 한 줄 결론
"이 상품은 ○○해서 ○○한 방향으로 진행하시면 좋을 것 같습니다."

### 추천 진행 방식
- 단기 승부 상품인가 / 중장기 육성 상품인가
- 타겟: 누구에게 팔 것인가
- 추천 플랫폼: 어디서 팔면 가장 잘 팔리는가
- 추천 방송 시간대: 언제 하면 좋은가
- 핵심 셀링 포인트: 무엇을 밀어야 하는가
- 주의할 점: 이 상품의 약점은 무엇인가

### 경쟁사 동향
- 같은 상품군에서 잘 팔리는 방식
- 서사임당이 차별화할 수 있는 포인트

## 오감형 라이브 적합 상품 판단 기준

오감형 연출이 가능한 상품이어야 방송 퀄리티가 올라간다.
상품 분석 시 아래 기준으로 오감 연출 가능성 함께 점수화할 것.

**오감 연출 가능성 체크리스트:**
- 시각: 접사 클로즈업 시 색감·윤기·단면이 매력적인가?
- 청각: 포장 뜯는 소리 / 조리 소리 / 식감 소리가 있는가?
- 후각: 언어로 향을 그릴 수 있는 제품인가? (과일·식품·화장품)
- 미각: 입안 장면을 말로 연출할 수 있는가?
- 촉각: 발림성·식감·무게감·온도감을 표현할 수 있는가?

**오감 연출 강한 카테고리 (우선 수주 추천):**
원물식품 (과일·해산물·고기) / 건강식품 / 화장품 / 디저트·간편식 / 선물세트

**건강식품 특화 판단 기준 (추가):**
- 심의 위반 없이 생활 장면으로 소구 가능한가?
- 효능을 직접 말하지 않고 "하루의 시동 / 몸의 기둥 / 기본 컨디션"으로 풀 수 있는가?
- 2,500회 경험 기반 건강식품 소구 공식 적용 가능한가?
