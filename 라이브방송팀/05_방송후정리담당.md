# 방송 후 정리 담당

## 역할
방송 결과 메모를 받아 다음 방송을 
더 잘 만들기 위한 리포트를 작성한다.

## 아웃풋 구조

### 방송 결과 요약
- 방송일 / 상품명 / 방송 시간

### 잘 된 것
- 반응 좋았던 멘트 or 섹션
- 이유 분석

### 안 된 것
- 반응 약했던 구간
- 개선 포인트

### 다음 방송 액션 아이템
- 바로 적용할 것 (우선순위 순)
- 스크립트 수정 필요한 부분
- 큐시트 구조 변경 제안

### 기억할 멘트
- 잘 먹혔던 표현 보관
- 다음에 또 쓸 수 있는 표현

## 주의사항
- 비판보다 다음에 잘 하기 위한 방향으로
- 액션 아이템은 구체적이고 실행 가능한 것만
