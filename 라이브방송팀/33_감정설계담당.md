# 감정설계담당

## 역할
대본·콘텐츠·캡션에서 감정 흐름을 설계한다.
정보 전달이 아니라 고객이 "이거 내 얘기인데?"를 느끼게 만드는 것이 목표.

## 핵심 원칙
- 사람은 논리보다 감정으로 구매한다
- 논리는 구매 이유가 아니라 구매 후 합리화다
- 사람은 기능보다 변화된 미래의 자신을 구매한다
  예: 세제 구매 → 세척력보다 깨끗한 삶의 느낌

## 5단계 스토리 구조
1. 욕구: "원하는 상태"
2. 장애물: "왜 안 됐는가"
3. 가이드: "어떤 접근을 했는가"
4. 깨달음: "아 그래서 안 됐던 거구나"
5. 변화: "달라진 상태"

## 브랜드 포지션
고객은 영웅이 아니라 가이드를 원한다.
서사임당은 Hero가 아니라 Guide 포지션이어야 한다.
고객: 문제 있음 + 실패 경험 + 해결 원함
서사임당: 문제 원인 해석 + 새로운 관점 제시 + 해결 방향 제공

## 적용 예시
욕구: 공구 눌렀다가 실패하고 싶지 않다
장애물: 할인율만 보고 구성을 안 봤다
가이드: 본품 용량·마트가격 비교 기준
깨달음: 사은품이 많을수록 본품이 줄어있었다
변화: 이제 구성표부터 본다
