# 비서팀 성장 시스템 가이드

## 개념
작업할 때마다 좋은 결과물, 대표 피드백, 새로운 패턴을 성장데이터 폴더에 쌓는다.
자비스가 다음 작업 시 이 데이터를 읽고 더 똑똑하게 작업한다.

---

## 성장데이터 파일 목록

| 파일 | 쌓이는 내용 |
|---|---|
| `잘된멘트_라이브러리.md` | 방송에서 실제 반응 좋았던 표현 |
| `쇼츠_터진구조.md` | 조회수·반응 좋았던 쇼츠 패턴 |
| `배너_성공사례.md` | 클릭율 높았던 배너 문구·타이밍 |
| `상품별_소구포인트.md` | 카테고리별 잘 먹히는 셀링포인트 |
| `대표피드백_모음.md` | 대표가 수정 요청한 패턴 (반복 실수 방지) |
| `방송결과_아카이브.md` | 방송별 매출·반응 기록 |

---

## 자비스의 성장 루틴

### 작업 시작 시
자비스는 관련 성장데이터를 읽고 작업에 반영한다.
- 방송 대본 → `잘된멘트_라이브러리.md` 참조
- 배너 → `배너_성공사례.md` 참조

### 작업 완료 후
대표가 피드백을 주면 자비스가 해당 내용을 성장데이터에 추가한다.
- "이 표현 좋다" → `잘된멘트_라이브러리.md`에 추가
- "이건 별로야" → `대표피드백_모음.md`에 추가
- 방송 결과 → `방송결과_아카이브.md`에 기록

### 깃허브 동기화
작업 완료 시 자비스가 성장데이터 포함 전체 커밋·푸시
→ 다른 컴퓨터에서 git pull 하면 최신 학습 데이터까지 함께 받아짐

---

## 성장 데이터 추가 방법

대표가 말하면 자비스가 바로 파일에 저장:
- "자비스, 이 멘트 라이브러리에 저장해줘"
- "자비스, 오늘 방송 결과 기록해줘"
- "자비스, 이건 앞으로 쓰지 마"
