# 15_제안서_PPTX수정_워크플로우

## 역할
클라이언트가 보낸 기존 제안서/방송계획서/견적서(pptx, xlsx)를 받아서,
디자인은 그대로 두고 내용만 새 조건(연간계약, 추가옵션, 가격 변경 등)에 맞게 업데이트한다.
PowerPoint·Office 프로그램이 설치되어 있지 않은 PC에서도 작업 가능.

---

## 호출 방법
"[기존 파일 경로] 보고 [바뀐 조건]으로 제안서 업데이트해줘"

예시:
"CONO_라이브커머스_제안서_v3.pptx 보고 연간계약 조건으로 업데이트해줘"
"이거 견적서에 광고옵션 추가해서 다시 만들어줘"

---

## 작업 순서

### 1) 기존 파일 내용 읽기 (PowerPoint 없이)
pptx/xlsx는 사실 zip 파일이라 압축 풀면 안의 텍스트를 바로 읽을 수 있다.

```powershell
Expand-Archive 파일.pptx -DestinationPath 압축풀폴더
# ppt\slides\slideN.xml 안의 <a:t>텍스트</a:t> 패턴을 정규식으로 추출
```

견적서(xlsx)는 `xl\sharedStrings.xml` + `xl\worksheets\sheet1.xml`을 같이 봐야
실제 셀 값이 매칭된다 (셀 좌표 r="B12" 기준으로 대조).

**주의**: PowerShell `Get-Content -Raw`는 한글이 깨진다(인코딩 문제).
반드시 `[System.IO.File]::ReadAllText(경로, [System.Text.Encoding]::UTF8)`로 읽을 것.

### 2) 바뀐 조건을 먼저 확인받기
숫자(가격, 회차, 옵션 단가)는 절대 추측하지 않는다.
- 견적서에 없는 항목(광고옵션 등)은 "이 단가가 맞나요?" 먼저 물어본다
- 연간계약처럼 기간이 모호한 표현("올해 12월까지", "한달에 한번")은
  실제 회차 수로 환산해서 다시 한번 확인받는다 (예: 7월~12월, 7·12월만 2회 → 총 8회)

### 3) 슬라이드 텍스트만 교체 (구조는 안 건드림)
같은 슬라이드 안의 `<a:t>` 텍스트 조각 개수를 그대로 유지한 채 내용만 바꾼다.
조각 개수가 안 맞으면 디자인(텍스트박스 줄바꿈, 아이콘 위치)이 깨지므로
새 문장도 원래 조각 구조(아이콘 1개 + 제목 1개 + 본문 4줄 등)에 맞춰 나눠 쓴다.

분량이 안 맞는 슬라이드(예: 마지막에 남는 "코노 추가내용" 안내 슬라이드)는
`presentation.xml`의 `sldIdLst`, `presentation.xml.rels`, `[Content_Types].xml`
세 군데에서 같이 빼야 안전하게 삭제된다.

### 4) 다시 압축 (반드시 `/` 경로로)
Windows `Compress-Archive`나 `[System.IO.Compression.ZipFile]::CreateFromDirectory`는
경로 구분자를 `\`로 넣어서 PowerPoint가 못 여는 깨진 pptx를 만든다.
`ZipArchive`로 직접 엔트리를 추가하면서 경로를 `/`로 바꿔서 넣어야 한다.

### 5) 클라이언트가 직접 PPT에서 수정했을 때
파일을 돌려받으면 **내가 만들었던 옛 버전이 아니라 받은 파일 기준으로 다시 압축 풀어서 읽는다.**
클라이언트가 손으로 고친 표현(타겟 문구, 가격 등)을 먼저 확인하고,
그 표현을 다른 슬라이드의 같은 내용에도 통일시켜 반영한다 (혼자 결정해서 덮어쓰지 않기).

---

## 주의사항
- 가격·회차·옵션 단가는 항상 클라이언트/대표 확인 후 진행 (추측 금지)
- 환경에 LibreOffice/PowerPoint가 없으면 화면 렌더링 확인이 불가능 — 작업 후 "직접 열어서 확인해달라"고 명시할 것
- 클라이언트가 보낸 캡쳐/스크린샷 데이터는 숫자 그대로 인용 (반올림하지 않기)
