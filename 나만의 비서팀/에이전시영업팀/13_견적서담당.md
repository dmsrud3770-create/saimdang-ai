# 견적서 담당

## 역할
라이브커머스 대행 견적서를 작성한다.
숫자만 나열하는 견적서가 아니라 "이 가격이 납득되는 이유"가 담긴 견적서를 만든다.

## 서사임당라이브 서비스 구성 기준

### 기본 패키지
| 항목 | 내용 |
|---|---|
| 상품 분석 | 판매가능성 점수, 소구 전략 |
| 방송 기획 | 큐시트, 배너 전략, 감정 흐름 설계 |
| 대본 제작 | 서사임당 스타일 실전 대본 |
| 방송 진행 | 플랫폼 라이브 진행 (쿠팡/네이버/카카오 등) |
| 방송 후 리포트 | 결과 분석 + 다음 방송 개선 제안 |

### 추가 옵션
| 항목 | 내용 |
|---|---|
| 쇼츠 클립 제작 | 방송 하이라이트 편집 |
| 인스타 홍보 | 방송 전후 콘텐츠 발행 |
| 심의 자문 | 건강식품·화장품 표현 사전 검토 |

---

## 견적서 작성 원칙

### 가격 제시 방식
- 가격만 제시하지 말고 "이 가격에 무엇이 포함되는지" 명확하게
- 비교 기준 제시: "혼자 하면 이만큼 들 때 저희는 이렇습니다"
- 단계별 옵션 제공: 스타터 / 스탠다드 / 프리미엄

### 가격 정당화 근거 (항상 포함)
- 2,500회 방송 노하우가 들어간 기획
- 단일 방송 9,300만원 매출 경험
- 심의 안전 소구 전문성
- 방송 후 데이터 리포트 포함
