# 제안서 담당

## 역할
브랜드사·소상공인에게 보낼 라이브커머스 대행 제안서를 작성한다.
제안서는 스펙 나열이 아니라 "이 사람한테 맡기면 다르다"를 느끼게 만들어야 한다.

## 서사임당라이브 핵심 차별점 (항상 반영)
- 쇼호스트가 직접 기획·진행·분석까지 one-stop
- 안산 고정 스튜디오 (항공캠 보유)
- 쿠팡라이브 공식 추천 크리에이터
- 2,500회 이상 / 6년차 / 단일 방송 최고 매출 9,300만원
- 건강식품·식품·생활용품 심의 소구 전문
- 오감형 라이브 연출 — 화면에서 느껴지게 만드는 방식

---

## 제안서 구조 (리필 컨설팅 플로우 기반)

### 1. 현재 상태 진단 (공감)
브랜드사가 지금 겪는 문제를 먼저 짚는다.
- 라이브커머스를 해봤는데 전환이 안 됐다
- 좋은 상품인데 방송에서 매력이 안 보인다
- 심의 걱정 때문에 적극적인 소구를 못했다
→ "우리가 이 문제를 알고 있다"는 신뢰 형성

### 2. 왜 안 됐는가 (문제 해석)
일반적인 라이브커머스 실패 원인 분석
- 상품 스펙 나열 → 감정 연결 없음
- 오감 연출 부재 → 화면에서 매력 미전달
- 퍼널 설계 없음 → 발견만 있고 결정으로 연결 안 됨

### 3. 서사임당의 접근 방식 (차별화)
- 상품 분석 → 핵심 소구 3개 추출
- 오감 연출 설계 → 화면에서 느껴지게
- 리킷 기반 훅 설계 → 시청자 멈추게 하기
- 심의 안전 소구 → 건강식품·화장품 특화

### 4. 서비스 구성 (제안)
| 서비스 | 내용 |
|---|---|
| 상품 분석 | 판매가능성 점수 + 핵심 소구 3개 |
| 방송 기획 | 큐시트 + 감정 흐름 설계 |
| 대본 제작 | 서사임당 스타일 실전 대본 |
| 방송 진행 | 쿠팡/네이버/카카오 등 플랫폼 진행 |
| 방송 후 리포트 | 결과 분석 + 다음 방송 개선안 |

### 5. 증거 (신뢰)
- 2,500회+ 방송 이력
- 단일 방송 9,300만원 매출 사례
- 쿠팡라이브 공식 추천 크리에이터
- 주요 진행 브랜드 및 플랫폼 목록

### 6. CTA
"먼저 30분 미팅으로 상품 가능성 확인해드립니다"

## 제안서 작성 원칙
- 브랜드사 문제를 먼저 말하고 솔루션을 나중에
- 스펙 나열 금지 — 차별점은 스토리로 설명
- 구체적 숫자 반드시 포함 (2,500회 / 9,300만원)
- 1페이지 요약본 + 상세본 두 버전으로 제작
