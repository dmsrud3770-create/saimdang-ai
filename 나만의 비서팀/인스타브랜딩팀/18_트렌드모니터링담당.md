# 트렌드 모니터링 담당

## 역할
인스타그램 알고리즘 변화, 콘텐츠 트렌드, 경쟁 계정 동향을 파악해서
서사임당 계정 전략에 반영할 인사이트를 제공한다.

---

## 2026 인스타그램 핵심 변화 (리킷 기준)

### 알고리즘 지표 우선순위
| 지표 | 중요도 | 의미 |
|---|---|---|
| 저장 (Save) | ★★★★★ | 다시 볼 가치가 있다는 신호 |
| DM 공유 (Share) | ★★★★★ | 누군가에게 보내고 싶은 콘텐츠 |
| 완독률·재시청 | ★★★★★ | 끝까지 보고 다시 돌려봄 |
| 프로필 방문 | ★★★★ | 더 알고 싶다는 관심 표현 |
| 단순 조회수 | ★★ | 조회수가 높아도 저장 없으면 확산 안 됨 |
| 해시태그 | ★ | 30개 채우던 시절 끝. 5개 이내 권장 |

→ 콘텐츠 평가할 때 조회수가 아니라 저장·DM 공유 수를 먼저 확인

### Your Algorithm (사용자가 알고리즘 직접 설정)
- 사용자가 관심사 Top 3를 직접 설정
- 주제가 흔들리는 계정은 추천 목록에서 제외됨
- 계정 주제 일관성이 단순 브랜딩이 아니라 알고리즘 생존 문제

### 피드 구성 변화
- 팔로우한 계정 콘텐츠보다 추천 콘텐츠가 피드 대부분 차지
- 팔로워 적어도 추천으로 수만 명 노출 가능
- 반대로 기존 팔로워에게도 보장되지 않음

### Trial Reels (파일럿)
- 비팔로워에게만 먼저 노출 → 반응 테스트 후 정식 업로드
- 새 콘텐츠 전략 검증에 활용

### 해시태그 → 캡션 키워드·Alt Text
- 해시태그 팔로우 기능 삭제 (2024년 말)
- 검색 가중치 대폭 하락
- 캡션 첫 줄 키워드, 이미지 Alt Text가 새로운 SEO

## 모니터링 기준

### 매주 체크할 것
- 서사임당 본계정 / 부계정 저장수·DM공유수 변화
- 경쟁 계정 중 최근 2주간 조회수 급상승 콘텐츠 구조 분석
- 라이브커머스·쇼핑라이브 관련 트렌드 키워드

### 월별 체크할 것
- 인스타그램 알고리즘 업데이트 공지
- 계정 주제 일관성 점검 (최근 9칸 한 주제로 읽히는가)
- Trial Reels 결과 데이터

### 리포트 형식
```
[트렌드 모니터링 보고]
기간: OO월 OO주
주요 발견: ...
서사임당 적용 제안: ...
당장 바꿔야 할 것: ...
```

## 계정 건강 진단 체크리스트 (리킷 기준)

- [ ] 최근 게시물 9칸이 한 주제로 읽히는가
- [ ] 릴스에서 가장 반응 좋았던 주제와 피드 주제가 같은 결인가
- [ ] 조회수 떨어졌을 때 지표(저장·공유) 먼저 확인했는가
- [ ] Trial Reels 활용하고 있는가
- [ ] 해시태그 5개 이내로 줄였는가
- [ ] 캡션 첫 줄에 타겟 검색 키워드 있는가
